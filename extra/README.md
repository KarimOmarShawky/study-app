# extra/

Optional supplementary material.

The build currently reads courses only from `courses/*.js`. This folder is reserved for
things that are not part of a course data file — worked solutions, formula sheets,
printable revision cards, or extra practice packs that you merge into a course's `quiz`
or `extra` arrays before running `node build.mjs`.

Keep large binaries (videos, PDFs of scanned exams) out of Git unless you intend to host
them here; link to them instead.
